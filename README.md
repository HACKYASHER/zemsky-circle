# Земский круг — онлайн-версия

Кооперативная историческая игра для 2–4 участников. В комплект входят сайт, Node.js-сервер, комнаты с приглашениями, синхронизация ходов и сохранение партий. Сервер нужен для общей игры: одного статического HTML-файла для этого недостаточно.

## Быстрая установка на Ubuntu

Рекомендуется Ubuntu 22.04/24.04 или Debian 12. Установщик ставит Docker из официального репозитория, собирает игру и выводит меню управления.

    sudo apt update
    sudo apt install -y git
    git clone https://github.com/HACKYASHER/zemsky-circle.git
    cd zemsky-circle
    sudo bash install-ubuntu.sh

Установщик попросит домен, проверит DNS и доступность портов, а затем предложит подходящий способ подключения. В меню доступны установка/обновление, просмотр состояния и удаление.

## Порты, домен и HTTPS

Перед установкой создайте у регистратора домена запись A, ведущую на IP-адрес сервера. Если у сервера настроен IPv6, проверьте и запись AAAA. У облачного провайдера также должны быть разрешены входящие подключения на используемый порт.

В установщике укажите свой домен в формате game.domain.com.

- Если свободны 80/tcp и 443/tcp, установщик запускает Caddy. Игра открывается по https://ваш-домен, а сертификат выпускается и обновляется автоматически.
- Если 80 или 443 заняты, установщик не останавливает существующий сайт. Он выбирает свободный игровой порт, начиная с 18300, и может запустить игру напрямую по адресу http://ваш-домен:порт. Откройте этот порт в firewall сервера и облачного провайдера.
- В режиме proxy приложение доступно только локально, а существующий веб-сервер направляет к нему запросы. Для установленного в Ubuntu Caddy установщик подключит домен, если конфигурация проходит проверку. Для Nginx он подготовит маршрут и предложит автоматически запросить сертификат Certbot. Для других прокси он подготовит примеры конфигурации в /etc/zemsky-circle/.

Игровой порт публикует отдельный Nginx-шлюз в обычной Docker-сети. Сам сервер игры остаётся во внутренней изолированной сети — так Docker может корректно открыть порт, не подключая приложение к внешней сети.

Страница игры использует относительные адреса CSS, JavaScript и приглашений. В прямом режиме сайт работает по HTTP; HSTS включается только за HTTPS-прокси. Если браузер уже запомнил HSTS для домена, он может сам заменять HTTP на HTTPS — тогда используйте HTTPS через существующий прокси или удалите сохранённую HSTS-политику для домена в браузере.

Браузер не подставляет нестандартный порт автоматически: для прямого режима в адресе обязательно указывать :порт. HTTPS на стандартном https://домен при занятом 443 должен обеспечивать уже работающий прокси. Если выбран прямой режим http://домен:порт, соединение не зашифровано; для публичного показа предпочтительнее подключить домен через HTTPS-прокси.

Для автоматического HTTPS Caddy нужен внешний доступ к challenge-портам. Подробности: [Caddy Automatic HTTPS](https://caddyserver.com/docs/automatic-https), [установка Docker Engine на Ubuntu](https://docs.docker.com/engine/install/ubuntu/).

## Управление

Повторно запустите установщик из папки проекта:

    sudo bash /opt/zemsky-circle/app/install-ubuntu.sh

Или используйте отдельные команды:

    sudo bash /opt/zemsky-circle/app/install-ubuntu.sh --update
    sudo bash /opt/zemsky-circle/app/install-ubuntu.sh --status
    sudo bash /opt/zemsky-circle/app/install-ubuntu.sh --remove

Обновление получает последнюю версию из GitHub и пересобирает контейнер игры. Сохранения партий хранятся отдельно от кода.

При удалении можно оставить сохранения и настройки или подтвердить полное удаление словом УДАЛИТЬ. Системный сертификат существующего прокси не удаляется. Docker и правила firewall остаются на сервере, так как ими могут пользоваться другие сайты.

## Запуск без установщика

Нужен Node.js версии 20 или новее:

    npm install
    npm start

По умолчанию локальный сервер слушает 127.0.0.1:3000. Для контейнера используются переменные HOST=0.0.0.0, PORT=3000 и DATA_DIR=/data.

## Комнаты и доступ

- В партии участвуют от 2 до 4 игроков.
- Комната закрытая: попасть в неё можно по коду или персональной ссылке.
- Ведущий может удалить участника до начала, закрыть комнату или начать партию заново после финала.
- Если ведущий выходит, права переходят другому подключённому игроку.
- В лобби место отключившегося игрока освобождается через 2 минуты. Во время партии место сохраняется, а ведущий может выбрать действие за отсутствующего участника.
- После перезагрузки страницы игрок возвращается по своей ссылке.
- Неактивная комната удаляется через 4 часа.
- По умолчанию ограничение — 50 комнат на сервер, 3 одновременно созданные комнаты с одного IP и 5 попыток создания за 15 минут. Также ограничены частые попытки входа по коду.

Настройки лимитов: MAX_ROOMS, MAX_ROOMS_PER_IP, ROOM_IDLE_HOURS в /etc/zemsky-circle/compose.env.

## Данные и масштабирование

Состояние комнат хранится в Docker-томе игры и переживает обновление контейнера. При полном удалении установщик отдельно просит подтверждение на удаление тома с сохранениями.

Приложение рассчитано на один экземпляр сервера и локальное хранилище. Для нескольких экземпляров потребуется общее хранилище и адаптер Socket.IO, например Redis. Имена участников и журнал доступны игрокам комнаты; учётных записей и сбора личных данных нет.
